# ATOM v0.1.0

This is the first public visibility release of ATOM, a finite-element single-atom DFT solver and density descriptor toolkit for machine-learned exchange-correlation research.

## Highlights

- Finite-element Kohn-Sham atomic DFT solver for all-electron and pseudopotential calculations.
- Exchange-correlation support including LDA, GGA-PBE, hybrid/exact-exchange workflows, and ML-XC interfaces.
- MCSH/generalized multipole descriptor generation from self-consistent electron densities.
- Dataset generation, loading, and ML-XC training interfaces.
- Validation report and figures for descriptor behavior and charge-conservation checks.
- Jupyter Book documentation with tutorials, cookbook material, and API reference.
- GitHub Actions CI and GitHub Pages documentation publishing.
